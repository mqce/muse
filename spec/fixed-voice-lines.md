# 固定セリフ一覧（事前合成WAV用）

デバイスに保存して再生する固定セリフのまとめ。VOICEVOX（雨晴はう）で事前合成してWAV化し、デバイス側に置く想定。
TTSサーバー（Windows PC）が止まっていても出せるのが利点。24kHz/16bit/モノラルで約48KB/秒が目安。

## 採用（第1弾、2026-11-28選定）

まずはこの4つからシンプルに始める。

| セリフ | 用途・発動条件 | ファイル名 | 状態 |
|---|---|---|---|
| 起きた | 起きた時（ねてる→通常への遷移時）。独り言のように言う | wake_up.wav | 作成済み（2026-11-28） |
| ふんふん | 嬉しい時（幸福ステートの時） | happy.wav | 作成済み（2026-11-28） |
| おーい | 呼びかけ。たいくつ ≥80 が1分継続、かつ通常（NORMAL）のとき。10分間隔で繰り返し | call.wav | 作成済み（2026-11-28） |
| ふむふむ | 考え中の間つなぎ。THINKING突入時に再生 | thinking.wav | 作成済み（2026-11-28） |

## 作り方

- Windows の VOICEVOX で作る（エンジンが既に立っている）。
- 一括生成スクリプト: `voice-lines/synthesize-voice-lines.ps1`（localhost:50021 のエンジンAPIを叩いて、話者「雨晴はう」で上の4ファイルを指定名で保存する）。
- 1つずつ作るなら VOICEVOX の GUI でも可。「起きた」の独り言っぽいイントネーションは GUI で調整すると出しやすい。
- 出力は VOICEVOX 既定の WAV（24kHz/16bit/モノラル）のままでよい。
